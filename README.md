FastAPI Bookmark Manager

REST API сервис для управления интернет-закладками.
Проект создан для практики backend-разработки на Python и глубокого 
знакомства с фреймворком FastAPI.
Позволяет сохранять ссылки, организовывать их с помощью тегов и быстро 
находить нужную информацию.

Функционал

Проект реализует полный CRUD для управления закладками:

Create — создание закладки с URL и тегами
Read — получение всех закладок или фильтрация по тегу
Update — редактирование закладки (ссылка или теги)
Delete — удаление закладки

Примечание: аутентификация и авторизация отсутствуют, так как проект 
учебный.

Технологии

- Python 3.12.1
- FastAPI
- SQLite + SQLAlchemy ORM
- Pydantic

Архитектура проекта

Код разделён на модули с чётким разделением ответственности:

models.py — описание структуры таблиц базы данных
schemas.py — схемы данных для валидации запросов и формирования ответов
db.py — настройка подключения к базе данных (engine) и сессий (Session)
main.py — маршруты (эндпоинты) и основная логика приложения

Проект реализует связь many-to-many между закладками и тегами, что 
отражает нормализованную модель хранения данных в реляционной базе.

Как запустить проект локально

1. Клонировать репозиторий
git clone <ссылка_на_repo>
cd BOOKMARK_MANAGER

2. Установить зависимости
pip install -r requirements.txt

3. Запустить сервер
uvicorn main:app --reload

Приложение будет доступно:
http://127.0.0.1:8000

API документация:
Swagger UI: http://127.0.0.1:8000/docs
ReDoc: http://127.0.0.1:8000/redoc
